# FizZion Security Checklist

- Row Level Security enabled and tested
- MFA enabled for privileged users
- Service-role keys kept server-side only
- Signed URLs used for private media access
- OAuth state validation enforced
- File uploads validated by type and checksum
- Audit logs enabled for privileged actions
- Rate limiting and CSP configured in the app layer
- Backup and restore procedure documented and rehearsed
