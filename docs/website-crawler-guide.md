# FizZion Website Crawler Guide

## Core rules

- Use an Iraq-geolocated browser node or approved proxy
- Respect site terms and access controls
- Do not bypass CAPTCHAs, paywalls, or logins

## Crawl cadence

- Default interval: every 15 minutes
- Override per website through `website_crawl_configs`

## Captured provenance

- Browser region
- IP region
- Language
- Viewport
- Consent state
- User agent
- Crawl run ID
